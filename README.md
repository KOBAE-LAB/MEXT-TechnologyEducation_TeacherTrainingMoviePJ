# 【MEXT-TeacherTrainingMoviePJ】D2 Library Recommend System

中学校技術・家庭科技術分野 D（2）
「ネットワークを利用した双方向性のあるコンテンツのプログラミングによる問題の解決」
に対応した動画教材開発用リポジトリです。

## 題材

**データでおすすめが変わる双方向コンテンツをつくろう**  
―図書室おすすめ本ナビを例に―

## 目的

図書室で本を選びにくいという身近な問題を出発点に、
本データを活用して、利用者の選択に応じておすすめ本を表示する
双方向コンテンツを構想・制作・評価する動画教材を開発します。

## 想定する学習内容

- 問題発見・課題設定
- データ表・リスト
- 条件検索
- スコア化
- クライアント・サーバ
- 双方向性
- AIによる構想・手順整理の支援
- 技術の利点・課題の評価
- 利用者・開発者・運用者の複数の立場からの改善

## 使用環境

標準実習環境として、なでしこ3を想定します。  
ただし、教材の中心は特定のプログラミング環境ではなく、
データを活用した双方向コンテンツの考え方に置きます。
