# 中学校技術科研修用動画 モデルプログラム

このリポジトリでは、文部科学省「令和8年度 学習指導要領の改訂を見据えた情報活用能力の抜本的な向上事業『中学校技術科教師の指導力向上のための研修の充実支援』事業」で制作した研修用動画に関連するモデルプログラムを公開します。

動画の視聴者が、動画内で扱われているプログラムを実際に動かし、動作を確かめ、授業や研修の目的に応じて修正・改善できるようにすることを目的としています。

## 収録内容

各動画教材のフォルダには、必要に応じて次のファイルを収録します。

- 動画内で使用したモデルプログラム
- プログラムが使用するサンプルデータ
- 実行方法と必要な環境
- 授業や研修で使用する際の補足説明
- 発展的な改良に取り組むためのヒント

教材によって、収録されるファイルの種類は異なります。

## 利用方法

1. 利用したい教材のフォルダを開きます。
2. フォルダ内のREADMEを読み、必要な環境や準備物を確認します。
3. モデルプログラムを指定されたプログラミング環境で開きます。
4. プログラムを実行し、動画で示された動作を確認します。
5. 必要に応じて、条件、データ、表示方法、処理方法などを変更します。

モデルプログラムは、完成したプログラムをそのまま利用するだけでなく、動作を確認し、問題点を見つけ、修正・改善する学習での利用を想定しています。

## 利用上の注意

- 本リポジトリのプログラムは、授業及び研修での利用を想定した学習用のサンプルです。
- 端末、ブラウザ、プログラミング環境のバージョンなどによって、表示や動作が異なる場合があります。
- 外部のWebサービス、Web API、クラウドサービスなどを使用する教材は、サービスの変更や終了によって動作しなくなる場合があります。
- サンプルデータには、実在する個人の情報や機密情報を入力しないでください。
- 学校で使用する場合は、学校や設置者が定める情報セキュリティ及び個人情報の取扱いに関する規程を確認してください。
- 改変したプログラムは、十分に動作を確認してから使用してください。
